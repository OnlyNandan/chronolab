# Self-Improvement Loop & Lessons Learned

*(Review this file at the start of every session. Update it after every correction made by the human.)*

- **2026-09-17**: The Doctor Mode agent hallucinated qualitative words ("improvement"). **Correction**: Ensure strict mathematical prompt constraints (e.g., "increased from X to Y") and actively forbid terms like "improvement" and "worsening".
- **2026-09-17**: `llava:7b` is prone to not being installed on local sandboxes. **Correction**: Always provide a graceful fallback to a text-only model (`qwen2.5:3b`) using PyMuPDF to extract text directly from the PDF if the vision run fails.
- **2026-09-20**: On Windows, piping non-ASCII text into `python -c '...' <<< "$var"` from bash silently mis-decodes it (caught: an em-dash in cedar/*.cedar comments became mojibake before being sent to AVP's create-policy call in bootstrap.sh). **Correction**: have Python read the file directly with `open(path, encoding='utf-8')` instead of going through a bash stdin heredoc/pipe, whenever a script shells out to Python with file content that might contain non-ASCII characters.
- **2026-09-20**: Any `aws` CLI call — even read-only ones like `sts get-caller-identity` — hits whatever account is configured in the current credential chain, which may not be the intended project's account. **Correction**: before running any `aws` command in an unfamiliar environment, check `aws sts get-caller-identity` first and confirm the account ID with the user before doing anything further, since a misconfigured/leftover credential chain can point somewhere unexpected.
- **2026-09-20**: When a script can't be tested live (no AWS account yet), a fake `aws` CLI stub on PATH that logs every invocation and returns canned output catches real bugs `bash -n` can't — it caught both the em-dash mojibake in Phase 3 and a dangling `https://` in a comma-joined CORS origin list in Phase 4 (empty `DUCKDNS_DOMAIN` wasn't filtered before joining). **Correction**: always dry-run non-trivial shell provisioning logic this way before shipping it, especially anything building JSON or comma-joined strings from optional variables.
